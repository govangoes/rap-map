# Rap Map Explorer UX Draft

## Overview
The Rap Map Explorer provides an interface for users to browse and compare rappers by unique word count. Each artist is presented in a card within a responsive grid. The card shows:
- Artist name
- Unique word count
- A horizontal bar indicating the count relative to others

## Interaction
- The page loads with a seed list of artists (MF DOOM, Aesop Rock).
- Users can toggle between grid and list view (planned future enhancement).
- Clicking an artist card will eventually show detailed stats and comparisons.

## Layout
- Use a responsive grid with adaptive columns that fit the viewport size.
- Cards have minimalistic styling (light border, subtle shadow) to keep focus on content.
- Bars use a primary accent color to visualize counts relative to the maximum value in the dataset.

This draft outlines the basic UX for the prototype explorer and can be refined as more features are added.
