Define manual and automated tests for the interactive explorer prototype to ensure correct functionality and basic accessibility.

- When loading the explorer, the two seeded artists (MF DOOM and Aesop Rock) should appear as separate cards.
- The width of each bar in the artist card should be proportional to the unique word count relative to the maximum count in the dataset.
- On different viewport widths, the grid should adjust the number of columns without overlapping or distorting content.
- Clicking on an artist card should open a detail view with more statistics (planned for future development).
- Text elements should meet contrast guidelines and bars should include aria labels or titles for screen reader users.

This outline provides a starting point for building unit tests and guiding manual QA as the explorer functionality expands.
